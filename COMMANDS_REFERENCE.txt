5. GOOGLE SHEETS OPERATIONS
================================================================================

# View jobs in Google Sheets (Python script)
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Jobs_v2'); jobs = gs.get_all_jobs(); [print(f'{i+1}. {j.get(\"Job Title\", \"N/A\")} at {j.get(\"Company\", \"N/A\")}') for i, j in enumerate(jobs)]"

# Count total jobs in sheet
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Jobs_v2'); print(f'Total jobs: {len(gs.get_all_jobs())}')"

# Check for specific company in sheet
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Jobs_v2'); jobs = gs.get_all_jobs(); [print(j.get('Job Title')) for j in jobs if 'Microsoft' in j.get('Company', '')]"

# Export jobs to CSV
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; import csv; gs = GoogleSheetsIntegration(); gs.connect('Jobs_v2'); jobs = gs.get_all_jobs(); f=open('jobs_export.csv','w',newline='',encoding='utf-8'); w=csv.DictWriter(f,fieldnames=jobs[0].keys()); w.writeheader(); w.writerows(jobs); f.close(); print('Exported to jobs_export.csv')"

# Find jobs posted today (contains 'ago' with hours)
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Jobs_v2'); jobs = gs.get_all_jobs(); [print(f'{j.get(\"Job Title\")} - {j.get(\"Posted\")}') for j in jobs if 'hour' in j.get('Posted', '').lower()]"

# Find jobs posted in last 24 hours
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Jobs_v2'); jobs = gs.get_all_jobs(); [print(f'{j.get(\"Job Title\")} - {j.get(\"Posted\")}') for j in jobs if 'hour' in j.get('Posted', '').lower() or 'minute' in j.get('Posted', '').lower()]"

# Find remote jobs in sheet
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Jobs_v2'); jobs = gs.get_all_jobs(); [print(f'{j.get(\"Job Title\")} - {j.get(\"Location\")}') for j in jobs if 'Remote' in j.get('Employment Type', '') or 'Remote' in j.get('Location', '')]"

# Find full-time jobs in sheet
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Jobs_v2'); jobs = gs.get_all_jobs(); [print(f'{j.get(\"Job Title\")}') for j in jobs if 'Full' in j.get('Employment Type', '')]"

10. BEST PRACTICES
================================================================================

RATE LIMITING:
- Wait 2-3 hours between large scraping sessions
- Use --limit 10-15 for regular searches
- Use --headless False for better success rate
- If rate limited, wait a few hours before trying again

SESSION MANAGEMENT:
- Re-run create_session.py every 1-2 weeks
- Keep linkedin_session.json secure
- Don't share your session file

GOOGLE SHEETS:
- Create new worksheet weekly for better organization
- Export to CSV regularly as backup
- Use descriptive worksheet names (e.g., "Week1_March", "Remote_Jobs")

SCRAPING STRATEGY:
- Morning: Check overnight postings (use "24 hours ago" filter on LinkedIn)
- Midday: Search specific roles
- End of week: Large batch scrape for next week

ORGANIZATION TIPS:
- Use separate worksheets for different job types
- Add date to worksheet names
- Export and backup regularly
- Review and clean up old jobs monthly
