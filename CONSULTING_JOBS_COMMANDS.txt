5. GOOGLE SHEETS OPERATIONS
================================================================================

# View all consulting jobs
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Consulting_Jobs_India'); jobs = gs.get_all_jobs(); print(f'Total consulting jobs: {len(jobs)}')"

# Count jobs by city
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Consulting_Jobs_India'); jobs = gs.get_all_jobs(); cities = {}; [cities.__setitem__(j.get('Search City', 'Unknown'), cities.get(j.get('Search City', 'Unknown'), 0) + 1) for j in jobs]; [print(f'{c}: {count}') for c, count in sorted(cities.items(), key=lambda x: x[1], reverse=True)]"

# Find SAP Consultant jobs
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Consulting_Jobs_India'); jobs = gs.get_all_jobs(); [print(f'{j.get(\"Job Title\")} - {j.get(\"Company\")} - {j.get(\"Search City\")}') for j in jobs if 'SAP' in j.get('Job Title', '')]"

# Find remote consulting jobs
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Consulting_Jobs_India'); jobs = gs.get_all_jobs(); [print(f'{j.get(\"Job Title\")} - {j.get(\"Location\")}') for j in jobs if 'Remote' in j.get('Employment Type', '') or 'Remote' in j.get('Location', '')]"

# Find jobs posted today (within hours)
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Consulting_Jobs_India'); jobs = gs.get_all_jobs(); [print(f'{j.get(\"Job Title\")} - {j.get(\"Posted\")} - {j.get(\"Search City\")}') for j in jobs if 'hour' in j.get('Posted', '').lower() or 'minute' in j.get('Posted', '').lower()]"

# Export to CSV
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; import csv; gs = GoogleSheetsIntegration(); gs.connect('Consulting_Jobs_India'); jobs = gs.get_all_jobs(); f=open('consulting_jobs_india.csv','w',newline='',encoding='utf-8'); w=csv.DictWriter(f,fieldnames=jobs[0].keys()); w.writeheader(); w.writerows(jobs); f.close(); print('Exported to consulting_jobs_india.csv')"

# Find Big 4 consulting jobs (Deloitte, PwC, EY, KPMG)
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Consulting_Jobs_India'); jobs = gs.get_all_jobs(); big4 = ['Deloitte', 'PwC', 'EY', 'KPMG']; [print(f'{j.get(\"Job Title\")} at {j.get(\"Company\")} - {j.get(\"Search City\")}') for j in jobs if any(b in j.get('Company', '') for b in big4)]"

# Find MBB consulting jobs (McKinsey, BCG, Bain)
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Consulting_Jobs_India'); jobs = gs.get_all_jobs(); mbb = ['McKinsey', 'BCG', 'Bain']; [print(f'{j.get(\"Job Title\")} at {j.get(\"Company\")} - {j.get(\"Search City\")}') for j in jobs if any(m in j.get('Company', '') for m in mbb)]"

# Count by employment type
python -c "from linkedin_scraper.integrations.google_sheets import GoogleSheetsIntegration; gs = GoogleSheetsIntegration(); gs.connect('Consulting_Jobs_India'); jobs = gs.get_all_jobs(); types = {}; [types.__setitem__(j.get('Employment Type', 'Unknown'), types.get(j.get('Employment Type', 'Unknown'), 0) + 1) for j in jobs]; [print(f'{t}: {c}') for t, c in sorted(types.items(), key=lambda x: x[1], reverse=True)]"

8. BEST PRACTICES FOR CONSULTING ROLES
================================================================================

SEARCH STRATEGY:
- Focus on Tier 1 cities first (Bangalore, Mumbai, Gurugram, Chennai, Pune)
- Run comprehensive scans on Monday mornings
- Do quick city-specific searches daily
- Filter for "posted in last 24 hours" on LinkedIn before scraping

CONSULTING FIRMS TO WATCH:
- Big 4: Deloitte, PwC, EY, KPMG
- MBB: McKinsey, BCG, Bain
- Tier 2: Accenture, Oliver Wyman, Kearney, L.E.K.
- IT Consulting: TCS, Infosys, Wipro, HCL, Tech Mahindra
- Boutique: ZS Associates, Mu Sigma, Fractal Analytics

KEYWORDS TO PRIORITIZE:
- "Management Consultant"
- "Strategy Consultant"
- "Business Consultant"
- "IT Consultant"
- "Senior Consultant"
- "Principal Consultant"
- "Lead Consultant"

ORGANIZATION TIPS:
- Use separate worksheets for different weeks
- Export to CSV every Friday
- Filter by city for location-specific applications
- Sort by "Posted" to find newest opportunities

RATE LIMITING:
- Wait 5+ seconds between cities (built-in)
- Use limit-per-city 10-15 for daily searches
- Use limit-per-city 20-25 for weekly comprehensive scans
- If blocked, wait 2-3 hours before retrying
