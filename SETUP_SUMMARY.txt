## 🔧 Troubleshooting

| Issue | Solution |
|-------|----------|
| "Failed to connect to Notion" | Check API key starts with `secret_`, verify integration connected |
| "No jobs added" | Check LinkedIn session, run in morning/evening for more 24h jobs |
| "Session not found" | Run `python samples/create_session.py` |
| "Column mismatch" | Your columns are already correct! (Company/Rich text, Position/Rich text, Date Posted/Date, Location/Rich text, Application Link/URL) |
