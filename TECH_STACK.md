# Tech Stack - Website

## Frontend

| Category | Technology |
|----------|------------|
| **Framework** | Next.js 14.2.35 (React 18.3.1) |
| **Language** | TypeScript |
| **Styling** | Tailwind CSS + PostCSS |
| **UI Components** | shadcn/ui (Radix UI primitives) |
| **Icons** | Lucide React |
| **Animations** | Framer Motion, Motion |
| **Forms** | React Hook Form + Zod validation |
| **Charts** | Recharts |
| **3D Graphics** | Spline Runtime |
| **PDF Handling** | @react-pdf/renderer, react-pdf, pdfjs-dist, jspdf |
| **Carousel** | Embla Carousel |
| **State/Utils** | class-variance-authority, clsx, tailwind-merge |

## Backend & Database

| Category | Technology |
|----------|------------|
| **Backend Runtime** | Express.js (Node.js) |
| **Database/Auth** | Supabase (PostgreSQL + Auth) |
| **Caching** | Upstash Redis |
| **Authentication** | JWT, bcryptjs, speakeasy (2FA) |
| **Email** | Nodemailer |

## Analytics & Monitoring

| Category | Technology |
|----------|------------|
| **Analytics** | Vercel Analytics, Mixpanel |
| **Performance** | Vercel Speed Insights |

## Testing & Quality

| Category | Technology |
|----------|------------|
| **Testing** | Vitest |
| **Linting** | ESLint (next/core-web-vitals) |

## Deployment & Build

| Category | Technology |
|----------|------------|
| **Deployment** | Netlify (with @netlify/plugin-nextjs) |
| **Package Manager** | pnpm |
| **Node Version** | 20+ |

## Additional Features

- Server-Sent Events (SSE) support
- QR code generation (qrcode)
- Confetti effects (canvas-confetti)
- Lottie animations
- PDF parsing (pdf-parse)
- CSV processing (papaparse, csv-parser)
- Firebase integration
- Rate limiting (express-rate-limit)
- File uploads (multer)
- Headless UI components (@headlessui/react)
- Date handling (date-fns)
- Country flags (flag-icons, country-list-json)
- PDF generation for browser (@react-pdf/renderer)
- Form validation with Zod schemas
- Sonner toast notifications
- Vaul modal dialogs
- cmdk command palette
